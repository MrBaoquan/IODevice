## ❓ 常见问题

### **Q1: 为什么 Phase 5 和 6 时间重叠？**
A: 可部分并行开发。媒体同步的基础设施不依赖预设系统，所以 Sprint 6.1 可与 Sprint 5.2 同时进行，实际可压缩 ~1 周。

### **Q2: 7月底为什么只交付 Sprint 7.1，不交付 Sprint 7.2？**
A: 优先级考虑。7月底需要核心功能 (Basic/Pro 分级) 可用，高级功能 (Undo/UI 美化等) 是锦上添花，可推迟至 8-10 月完成。

### **Q3: 如何应对进度延期？**
A: 按优先级递减：
- **P0 (7月必须):** Phase 1-6 全部 + Phase 7.1
- **P1 (8月目标):** Phase 7.2 主要功能
- **P2 (9-10月):** UI 美化、OutputTest 等可选项

### **Q4: 单人开发是否现实？**
A: 现实但紧张。建议：
- 利用并行开发机会压缩周期
- 适当降低 P2 优先级项的完善度
- 预留 Phase 之间的缓冲测试时间
