# 事件转发配置功能说明

## 功能概述

事件转发配置窗口用于配置Key到Key的映射关系，当接收到源Key时，会将其转发到指定的目标设备的目标Key。

## 如何打开配置窗口

1. 启动应用程序
2. 在菜单栏选择：**编辑** → **事件转发配置**

## 主要功能

### 1. 添加映射
- 点击工具栏的 **➕ 添加映射** 按钮
- 自动创建一个新的映射条目
- 在右侧编辑区域填写详细信息：
  - **源Key**：接收的键值输入
  - **目标Key**：要转发的键值
  - **目标设备地址**：格式为 `IP:端口`（例如：192.168.1.100:8080）
  - **启用状态**：勾选框控制是否启用此映射
  - **说明备注**：可选的描述信息

### 2. 编辑映射
- 在左侧列表中选择要编辑的映射
- 在右侧编辑区域修改各字段
- 修改会实时反映到左侧列表
- 预览区显示当前映射的完整信息

### 3. 删除映射
- 在左侧列表中选择要删除的映射
- 点击工具栏的 **🗑️ 删除** 按钮

### 4. 调整顺序
- 选择映射后，使用 **⬆️ 上移** 或 **⬇️ 下移** 按钮调整执行顺序

### 5. 保存配置
- 点击工具栏的 **💾 保存配置** 按钮
- 配置将保存到：`Config/EventForwardConfig.json`
- 下次打开窗口会自动加载

### 6. 重新加载
- 点击工具栏的 **📂 重新加载** 按钮
- 从配置文件重新加载所有映射

## 配置文件格式

配置文件保存在：`Config/EventForwardConfig.json`

```json
{
  "Mappings": [
    {
      "SourceKey": "KeyA",
      "TargetKey": "KeyB",
      "TargetDevice": "192.168.1.100:8080",
      "IsEnabled": true,
      "Description": "将KeyA映射到KeyB"
    }
  ]
}
```

## 使用示例

### 示例1：将空格键转发为回车键
- **源Key**: `Space`
- **目标Key**: `Enter`
- **目标设备**: `192.168.1.100:8080`
- **说明**: 将本地空格键输入转发为远程回车键

### 示例2：键盘方向键映射
- **源Key**: `W`
- **目标Key**: `Up`
- **目标设备**: `192.168.1.101:9000`
- **说明**: 将W键转发为上箭头键

## 注意事项

1. **目标设备地址格式**：必须是 `IP:端口` 格式
2. **键值命名**：建议使用统一的键值命名规范
3. **启用状态**：临时禁用某个映射时，取消勾选即可，无需删除
4. **保存配置**：修改后记得点击保存按钮
5. **配置文件**：可以手动编辑 JSON 文件，但要确保格式正确

## UI说明

- **左侧列表**：显示所有映射的简要信息（源Key → 目标Key）
- **右侧编辑区**：显示选中映射的详细信息和编辑表单
- **顶部工具栏**：快速操作按钮
- **底部状态栏**：显示配置文件路径和映射总数
- **预览区**：实时显示当前编辑的映射信息

## 键值对应关系

源Key接收到输入后，会按照配置的映射关系，将对应的目标Key发送到指定的目标设备。

```
本地接收: SourceKey  →  网络转发: TargetKey @ TargetDevice
```
