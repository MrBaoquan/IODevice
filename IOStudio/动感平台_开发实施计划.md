# 动感平台播控系统 — 实施计划

> 配套架构文档：[动感平台编辑系统\_架构设计.md](动感平台编辑系统_架构设计.md) (v22)

---

## 〇、系统目标

构建 **4D/5D 影院动感特效编辑与播控系统**，包括两部分：

| 产出物           | 说明                                               | 用户            |
| ---------------- | -------------------------------------------------- | --------------- |
| **IODevice.dll** | C++20 核心 — 设备驱动 + 嵌入式 MotionPlayer 运行时 | Unity/UE 开发者 |
| **IOStudio.exe** | Avalonia 桌面应用 — 设备监控 + 时间轴编辑 + 播控   | 工程师/内容制作 |

**两条集成路径：**

- **路径 A 直接嵌入** — Unity/UE 加载 IODevice.dll，调用 `IOToolkit.MotionPlayer.LoadSlot()` / `PlaySlot()`
- **路径 B TCP 播控** — IOStudio 作为独立播控服务，Unity/UE 通过 TCP:9600 JSON 命令远程控制

> **目标：** 解决"一个效果需要多通道联动"和"预设跨设备复用"问题。将效果预设从单通道曲线模板升级为多通道组合效果预设，并引入通道角色映射机制，实现同一预设跑在 3DOF/6DOF 不同平台。

#### 4.8.1 三层预设体系

| 层 | 名称 | 说明 |
|----|------|------|
| ① | `EffectPreset` 效果预设 | 多通道联动模板，用户直接拖拽的积木块。含通道角色列表 + 参数化接口 |
| ② | `CurveTemplate` 曲线模板 | 单通道的关键帧序列，可被多个效果预设引用（复用已有 `MotionKeyframe`） |
| ③ | `Keyframe` 关键帧 | 基础层，复用现有 `MotionKeyframe` 模型 |

> **设计约束（重要）：** 代码层**不区分任何轴语义**（Lift/Pitch/Yaw 等）。IOStudio 编排的所有通道都是**自由命名的开关量/模拟量通道**，具体语义由业务层/配置层定义。通道标识别、设备模板映射均为自由字符串，与现有 `MotionTrack.DeviceName / OActionName / OAxisChannel` 的字符串化设计保持一致。

#### 4.8.2 核心模型

| 模型 | 说明 |
|------|------|
| `EffectPreset` | 预设顶层：`Id` / `Name` / `Category` / `DurationMs` / `DefaultIntensity` / `Channels[]` |
| `PresetChannel` | 逻辑通道：`Role`(**自由字符串**, 预设作者自定义标签) / `Scale`(幅度系数) / `PhaseOffsetMs`(相位错峰) / `TemplateRef` 或内联 `Keyframes[]` |
| `DeviceTemplate` | 设备模板：`Name` + `RoleMap`(Dictionary<**string**, string>，自由字符串 → 通道名)，定义某类设备的默认角色布局，语义在此层由业务定义 |
| `PresetParameterApplier` | 参数化重采样器：输入预设 + 目标强度/时长 → 生成新的 `MotionKeyframe[]` → `MotionClip` |

> **角色字符串只是预设作者的约定标签**（如 `"heave"`、`"tilt_forward"`、`"升降轴"`、`"OAxis_00"` 均可），引擎与编辑器代码不解释、不校验其语义；跨设备复用时由 `DeviceTemplate.RoleMap` 在业务配置层完成到实际通道名的映射。

#### 4.8.3 跨设备复用机制

预设用自由字符串角色标签描述，应用时按设备模板映射到实际通道名：

```
预设「失重上升」标签示例：        6DOF 平台 (DeviceTemplate)         3DOF 座椅 (DeviceTemplate)
  role "heave"    Scale 1.0  →   OAxis_02 (Heave)                 OAxis_00 (Heave)
  role "pitch"    Scale 0.4  →   OAxis_03 (Pitch)                 OAxis_01 (Pitch)
  role "roll"     Scale 0.2  →   OAxis_04 (Roll)                  <跳过> (无此通道)

预设「升降设备」标签示例：        升降设备 (DeviceTemplate)          转台 (DeviceTemplate)
  role "升降轴"   Scale 1.0  →   OAxis_00                          OAxis_02
  role "转台"     Scale 0.3  →   <跳过> (无此通道)                 OAxis_01
```

> **注意：** 上例中的 `"heave"`、`"pitch"`、`"升降轴"` 均为预设作者自定义的自由字符串标签，非代码层枚举。引擎/编辑器代码零语义解释。

- 映射挂载点：`MotionTrack` 增加可选 `role` 字段（自由字符串），或项目级 `device_templates` 配置中的 `RoleMap`（`Dictionary<string, string>`）；
- 缺失角色：跳过并提示，不阻断预设应用；
- 角色匹配后，PresetParameterApplier 生成 Clip 落轨，用户可继续用曲线编辑器精调。

#### 4.8.4 预设参数化

| 参数 | 范围 | 作用 |
|------|------|------|
| `Intensity` | 0.2~1.2 | 整体缩放各通道幅度：`value' = 0.5 + (value - 0.5) × I × channelScale` |
| `Speed` | 0.5x~2x | 时间缩放：`time' = time × speedFactor` |
| `Duration` | 自定义 | 时长重采样，线性插值到目标时长 |
| `ChannelScale` | 预设内 | 通道级幅度系数，联动错峰 |

参数化只发生在"生成时刻"，落轨后的 Clip 是普通关键帧序列，可继续精调。

#### 4.8.5 预设库组织

| 类别 | 预设示例 |
|------|----------|
| 🔥 失重效果 | 失重上升(3通道) / 失重下降(3通道) / 失重悬浮(2通道) / 失重波动(2通道) |
| 🎢 过山车 | 俯冲 / 急转弯 / 爬坡 |
| 💥 冲击震动 | 撞击震动(多通道高频) / 急停 / 颠簸 |
| 🌬 特效 | 风(单通道) / 烟雾(bool) |

#### 4.8.6 复用路径

| 方式 | 说明 |
|------|------|
| 跨设备 | 同一预设靠角色映射跑在 3DOF/6DOF 不同平台 |
| 参数化 | 同一预设通过 intensity/duration 适配不同行程/重量的设备 |
| 组合 | 时间轴上预设A+预设B拼接/重叠，另存为新预设 |
| 继承 | 预设支持 `BaseId`，子预设覆盖部分通道 |
| 跨项目 | `.mfx` 文件导出/导入/分享，与工程解耦 |
