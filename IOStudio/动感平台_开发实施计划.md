> 配套架构文档：[动感平台编辑系统\_架构设计.md](动感平台编辑系统_架构设计.md) (v16)

## 〇、系统目标

构建 **4D/5D 影院动感特效编辑与播控系统**，包括两部分：

| 产出物           | 说明                                               | 用户            |
| ---------------- | -------------------------------------------------- | --------------- |
| **IODevice.dll** | C++20 核心 — 设备驱动 + 嵌入式 MotionPlayer 运行时 | Unity/UE 开发者 |
| **IOStudio.exe** | Avalonia 桌面应用 — 设备监控 + 时间轴编辑 + 播控   | 工程师/内容制作 |

**两条集成路径：**

- **路径 A 直接嵌入** — Unity/UE 加载 IODevice.dll，调用 `IOToolkit.MotionPlayer.LoadSlot()` / `PlaySlot()`
- **路径 B TCP 播控** — IOStudio 作为独立播控服务，Unity/UE 通过 TCP:9600 JSON 命令远程控制
