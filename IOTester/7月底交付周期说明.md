## 🎯 7月底交付 (M4) 核心内容

### **交付日期：** 2026-07-04 (第 17 周)

### **交付成果：**

```
IOTester.exe (单一二进制)
├── Basic 模式（免费）
│   ├── TCP:9600 MotionServer (play/pause/stop/seek/list_files)
│   ├── .mtn 文件播放（AES-256-GCM 解密）
│   ├── 简单的对讲测试工具（OutputTest）
│   └── 设备连接 + 驱动
│
├── Pro 模式（付费，需 LicHper 授权）
│   ├── 完整时间轴编辑器
│   │   ├── 轨道管理（添加/删除/重命名）
│   │   ├── 关键帧编辑（add/delete/move/多选）
│   │   ├── 贝塞尔曲线编辑器
│   │   └── 效果预设库（拖拽应用）
│   ├── 媒体同步（视频/音频 + 时间轴联动）
│   ├── 导出功能
│   │   ├── .motion （明文 JSON，供开发用）
│   │   └── .mtn （AES-256-GCM 加密，供发行用）
│   └── 高级功能
│       ├── Undo/Redo
│       ├── 自动保存 + 崩溃恢复
│       ├── 快捷键体系
│       └── 性能优化（>1000 关键帧）
│
└── 授权管理面板
    ├── 查看授权状态（Basic/Pro）
    ├── 导入 License token
    ├── 激活/注销
    └── BIOS UUID 绑定机制
```

### **技术特性：**

| 特性 | Basic | Pro | 实现方式 |
|------|-------|-----|---------|
| TCP 播控 | ✅ | ✅ | MotionCommandHandler 区分模式 |
| .mtn 播放 | ✅ | ✅ | MotionCryptoService 解密 |
| 时间轴编辑 | ❌ | ✅ | MainWindowViewModel CanExecute 门控 |
| 导出 .mtn | ❌ | ✅ | 菜单禁用 + LicenseService.IsPro 检查 |
| IL 混淆 | ✅ | ✅ | Obfuscar 混淆逻辑 + UI 隐藏关键变量 |
| DXGI 水印 | ✅ | ✅ | LicHper.dll 内置（作为威慑） |

### **授权流程：**

```
新用户安装 IOTester.exe
    ↓
启动 → LicenseService.Initialize()
    ↓
Validate("IOTester.Pro", 1)  [查询 ~/.authrc]
    ↓
    ├─ 返回 0 (Pro) → 解锁所有功能
    │
    └─ 返回 10002 (Basic) → 菜单显示 🔒, CanExecute = false
        ↓
        用户可选：设置 → 授权管理 → 导入 License Token
        ↓
        Login(token) → Validate() → Pro 模式激活
```
