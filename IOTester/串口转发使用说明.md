# 串口转发功能使用说明

## 功能概述
串口转发功能允许将源设备的按键事件通过串口发送自定义数据到外部设备。

## 配置步骤

### 1. 创建自定义模式协议组
1. 创建新协议组
2. 协议类型选择：`Custom`（自定义）
3. 配置源设备：选择接收按键输入的设备
4. 自定义协议类型选择：`Serial`（串口）

### 2. 配置串口参数
- **串口号**：
  - 从下拉列表中选择系统可用的串口（如 COM1, COM3 等）
  - 系统会自动检测并列出所有可用的COM口
  - 点击右侧的刷新按钮可重新扫描COM口
  - 如果新插入USB串口设备，点击刷新按钮即可看到
- **波特率**：设置通信速率（如 9600, 115200 等）
- **数据位**：通常为 8
- **校验位**：选择校验方式
  - None（无校验）
  - Odd（奇校验）
  - Even（偶校验）
  - Mark
  - Space
- **停止位**：通常为 1 或 2

### 3. 添加映射配置
1. 在协议组中添加映射
2. 配置源Key（如 Button_01）
3. 选择数据格式：
   - **ASCII**：发送文本数据
   - **HEX**：发送十六进制数据

4. 配置事件数据：
   - **Pressed 事件数据**：按下时发送的内容
   - **Released 事件数据**：释放时发送的内容

## 数据格式说明

### ASCII 格式
直接输入要发送的文本内容，系统会自动转换为字节发送。

**示例：**
```
Pressed数据: BUTTON_01_ON
Released数据: BUTTON_01_OFF
```

### HEX 格式
输入十六进制字节，支持以下格式：
- 空格分隔：`48 65 6C 6C 6F`
- 连续输入：`48656C6C6F`
- 带0x前缀：`0x48 0x65 0x6C 0x6C 0x6F`
- 短横线分隔：`48-65-6C-6C-6F`

**示例：**
```
Pressed数据: FF 01 AA BB
Released数据: FF 00 AA BB
```

## 工作原理

### 连接管理
- 系统会自动管理串口连接
- 首次发送数据时自动打开串口
- 使用配置的参数（波特率、数据位等）
- 连接失败会在日志中输出错误信息

### 数据发送流程
1. 检测到按键事件（Pressed 或 Released）
2. 根据事件类型选择对应的数据（PressedData 或 ReleasedData）
3. 如果数据为空，跳过发送
4. 根据数据格式解析为字节数组
5. 通过串口发送字节数据

### 连接复用
- 相同串口配置（端口号+参数）的映射共享同一个串口连接
- 提高性能，避免重复开关端口
- 服务停止时自动关闭所有串口

## 配置示例

### 示例1：简单开关控制
```xml
<ProtocolGroup GroupName="串口控制组" 
               ProtocolType="Custom" 
               CustomProtocolType="Serial"
               SourceDevice="ExtDev"
               SerialPort="COM3"
               BaudRate="9600"
               DataBits="8"
               Parity="None"
               StopBits="1">
  <Mappings>
    <Mapping SourceKey="Button_01" 
             DataFormat="ASCII"
             PressedData="LED1_ON"
             ReleasedData="LED1_OFF"
             IsEnabled="true"/>
  </Mappings>
</ProtocolGroup>
```

### 示例2：多按键HEX协议
```xml
<ProtocolGroup GroupName="HEX协议控制" 
               ProtocolType="Custom" 
               CustomProtocolType="Serial"
               SourceDevice="ExtDev"
               SerialPort="COM5"
               BaudRate="115200"
               DataBits="8"
               Parity="Even"
               StopBits="1">
  <Mappings>
    <Mapping SourceKey="Button_01" 
             DataFormat="HEX"
             PressedData="AA 01 FF BB"
             ReleasedData="AA 01 00 BB"
             IsEnabled="true"/>
    <Mapping SourceKey="Button_02" 
             DataFormat="HEX"
             PressedData="AA 02 FF BB"
             ReleasedData="AA 02 00 BB"
             IsEnabled="true"/>
  </Mappings>
</ProtocolGroup>
```

### 示例3：单向触发（仅Pressed）
```xml
<Mapping SourceKey="Button_03" 
         DataFormat="ASCII"
         PressedData="TRIGGER"
         ReleasedData=""
         IsEnabled="true"/>
```
> 释放数据为空时，释放事件不会发送任何数据

## 常见问题

### Q1: 串口无法打开
**可能原因：**
- 串口已被其他程序占用
- 串口号不存在
- 没有权限访问串口
- 串口参数配置错误

**解决方法：**
- 关闭其他占用串口的程序
- 点击刷新按钮确认串口号在系统中存在
- 如果是USB串口，检查驱动是否正确安装
- 以管理员权限运行程序
- 检查波特率、数据位等参数是否正确

### Q2: 数据发送失败
**可能原因：**
- 串口连接断开
- 硬件故障
- 数据格式错误

**解决方法：**
- 检查串口线缆连接
- 验证外部设备是否正常工作
- 确认HEX格式数据正确（偶数个字符）
- 查看调试日志获取详细错误信息

### Q3: 外部设备没有响应
**可能原因：**
- 串口参数不匹配
- 数据格式与设备协议不符
- 外部设备未正确配置

**解决方法：**
- 确认波特率、校验位等参数与外部设备一致
- 使用串口调试工具验证数据是否正确发送
- 参考外部设备的通信协议文档

## 调试技巧

### 刷新COM口列表
- 在串口号选择框右侧有刷新按钮（🔄图标）
- 当插入新的USB串口设备后，点击刷新按钮即可更新列表
- 系统启动时会自动扫描一次可用COM口
- 如果显示"未检测到串口"，请检查硬件连接并刷新

### 查看日志输出
系统会在Debug输出中显示详细的串口操作信息：
```
[Serial] Opened COM3 at 9600 baud
[Serial] Sent 5 bytes to COM3
[Serial] Failed to open port: 端口'COM3'不存在
```

### 使用串口调试工具
推荐使用以下工具验证通信：
- **Serial Port Monitor**：监控串口通信
- **Termite**：串口终端工具
- **RealTerm**：高级串口调试工具

### 逐步测试
1. 先用串口调试工具测试外部设备
2. 确认正确的通信参数和协议
3. 在IOTester中配置相同参数
4. 添加简单的单个映射测试
5. 逐步增加复杂配置

## 性能优化

### 连接复用
- 相同端口配置的多个映射自动共享连接
- 避免频繁开关串口

### 错误恢复
- 发送失败时自动关闭并移除连接
- 下次发送时尝试重新打开
- 不会影响其他串口的正常工作

### 资源清理
- 服务停止时自动关闭所有串口
- 释放系统资源
- 确保其他程序可以使用串口

## 技术规格

### 支持的串口参数
- **波特率**：300 - 921600 bps（常用：9600, 115200）
- **数据位**：5 - 8（推荐：8）
- **校验位**：None, Odd, Even, Mark, Space
- **停止位**：1, 2

### 数据限制
- **最大数据长度**：无限制（受硬件和缓冲区限制）
- **发送延迟**：取决于波特率和数据长度
- **并发连接**：支持多个串口同时工作

### 依赖库
- **System.IO.Ports** (Version 8.0.0)
- .NET 6.0 或更高版本
