# 批量范围映射功能说明

## 功能概述
批量范围映射功能允许您快速生成多个连续的按键映射配置，无需逐个手动添加。

## 使用方法

### 1. 打开批量映射对话框
有两种方式打开批量映射对话框：

**方式一：顶部工具栏**
1. 选中一个协议组
2. 点击顶部工具栏的 "批量添加范围映射" 按钮（紫色按钮）

**方式二：右键菜单**
1. 右键点击任意协议组
2. 在弹出菜单中选择 "批量添加范围映射"

### 2. 配置映射参数

**源配置：**
- **源Key前缀**: 输入键名前缀，如 `Button_`
- **起始通道号**: 输入起始通道编号，如 `0`
- **结束通道号**: 输入结束通道编号，如 `15`

> **注意**：源设备现在在协议组级别配置，不在此对话框中设置。

**目标配置：**
- **目标Key前缀**: 输入目标键名前缀，如 `Button_`
- **起始通道号**: 输入目标起始通道编号，如 `0`
- **结束通道号**: 输入目标结束通道编号，如 `15`

**其他选项：**
- **启用所有生成的映射**: 勾选后，所有生成的映射默认启用
- **批注说明**: 可选，为这批映射添加统一的说明文字

### 3. 预览和确认
- 对话框会实时显示源通道范围预览和目标通道范围预览
- 显示将要生成的映射数量
- 显示映射示例（第一个和最后一个映射）

### 4. 生成映射
点击 "确认生成" 按钮后：
- 系统会根据配置自动生成所有映射
- 映射会添加到当前选中的协议组中
- 协议组会自动展开显示新添加的映射

## 使用示例

### 示例 1：简单的1对1映射
```
源Key前缀: Button_
源起始通道: 0
源结束通道: 15

目标Key前缀: Button_
目标起始通道: 0
目标结束通道: 15

生成结果:
Button_00 → Button_00
Button_01 → Button_01
...
Button_15 → Button_15
（共16个映射）
```

### 示例 2：偏移映射
```
源Key前缀: Button_
源起始通道: 0
源结束通道: 7

目标Key前缀: Button_
目标起始通道: 10
目标结束通道: 17

生成结果:
Button_00 → Button_10
Button_01 → Button_11
...
Button_07 → Button_17
（共8个映射）
```

### 示例 3：不同前缀映射
```
源Key前缀: Input_
源起始通道: 1
源结束通道: 4

目标Key前缀: Output_
目标起始通道: 1
目标结束通道: 4

生成结果:
Input_01 → Output_01
Input_02 → Output_02
Input_03 → Output_03
Input_04 → Output_04
（共4个映射）
```

## 注意事项

1. **通道号范围**: 起始通道号必须小于或等于结束通道号
2. **映射数量**: 如果源和目标的通道数量不同，系统会取较小的数量生成映射
3. **通道号格式**: 生成的通道号会自动格式化为两位数（如 00, 01, 02...）
4. **协议组选择**: 必须先选中一个协议组才能使用批量映射功能
5. **映射编辑**: 生成后，每个映射仍可单独编辑或删除

## 优势

- ⚡ **快速**: 一次操作生成多个映射，节省时间
- 🎯 **准确**: 避免手动输入错误
- 📝 **灵活**: 支持自定义前缀和通道范围
- 🔄 **可编辑**: 生成后的映射可单独调整
